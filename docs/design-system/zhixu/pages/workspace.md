# 企业知识工作台覆盖规则

适用于登录、问答、文档和成员页面。检索生成的通用 SaaS 营销页建议不直接用于工作台；采用已核对的 Minimalism & Swiss Style 建议：清晰导航、足够留白、克制动效。

- 配色：背景 #f5f7f5，表面 #ffffff，主文字 #223d35，次文字 #62736c，主操作 #205b4b / 白色文字。浅绿色仅作背景。
- 桌面：232px 侧栏 + 主工作区；问答页右侧证据说明栏。小屏收为顶栏和横向三项导航，禁止页面横向溢出。
- 字体：系统字体 + PingFang SC / Microsoft YaHei，无外部字体请求。
- 按钮至少 44px 高，表单有可见标签，焦点环清晰；所有图标使用 Lucide SVG。
- 问答、下载、上传均显示真实状态。示例模式常驻标识，不伪装成已接通模型。
- 确认弹窗使用原生 dialog，支持 Escape、焦点约束和关闭后焦点返回。
- 文本使用 React 转义与安全 Markdown，长文件名允许换行。支持 prefers-reduced-motion。
